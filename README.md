# Blueprint Studio · 可视化插件引擎

一个**轻量级的"虚幻5式"引擎**（纯蓝图工作流分支）：逻辑用蓝图编辑，一键运行——
通过 **Agent 会话插件**连接 `dsh-plugin-orchestrator`，让蓝图直接驱动 DSH 内的 Agent
会话（Codex / Claude 预留）。

- 前端：React 18 + TypeScript + Vite + React Flow（蓝图编辑器 + 运行时）
- 后端：Node + WebSocket（源适配器 / 资产仓 / RPC），**无轮询，全实时推送**
- 引擎：Web Worker 图解释器（控制流 + 数据流混合，仿 UE 蓝图语义，支持子蓝图）

## 快速开始

```bash
npm install
npm run server    # 后端 :8790（WS + 资产 + RPC）
npm run dev       # 前端 :5173（另开一个终端）
npm run typecheck # 类型检查
npm run roundtrip # 蓝图⇄脚本往返一致性单测（含子蓝图段落）
npm run build     # 生产构建（后端可直接托管 dist/）
```

## Agent 会话插件（默认安装）

`plugins-registry/agent.json` 随引擎分发（默认安装）；未安装时 Agent 相关节点与
「会话 (session)」变量类型**完全不显示**。

- **创建 Agent 会话**：创建会话并返回会话值（赋给会话类型变量）；标题留空 = 使用
  DSH 自动生成的标题；工作区 = 当前蓝图项目目录（幂等复用）；大模型引脚经编排器
  `agentPreset` 传递；平台可选 DSH / Codex（预留）/ Claude（预留）。
  内部设置（检视面板「内部设置」分组，不占引脚）：**大模型**（下拉读 DSH 模型目录）、
  **工作区**（可点「选择目录」浏览项目子目录或手填绝对/相对路径，留空 = 项目目录）、
  **复用已有会话**（勾选后按会话标题 + 工作区搜索复用，标题为空或搜索不到才新建）。
- **会话事件**：监听会话通知（检视器选会话变量，仅该会话触发）；出脚：通知类型
  （created / status / turn-start / turn-end / completed / interrupted / failed）、
  内容、原始 JSON、会话ID。
- **发送 Agent 消息**：检视器填消息内容（提示词）发送给会话；勾选「等待完成通知」
  （默认勾选）时阻塞等待会话空闲并回读最终回复（`reply` 出脚），否则立即结束。
- **删除 Agent 会话**：归档会话（运行中的回合先取消），从工作区导航隐藏（日志保留）。
- **大模型 / 思考强度 / 权限**：下拉直接读取 DSH 本机配置——模型目录与思考强度读
  `~/.dsh/settings.yaml`，权限预设读 profile 的 `cordis.patch.yml`
  （`@deepseek-ai/dsh-permission-presets`）；会话连线时按上游节点的平台取对应目录。

DSH 连接：编排插件**不自行监听端口**，REST 网关挂在 DSH web 宿主上（契约见
`server/agents/types.ts`）。服务端自动探测 `127.0.0.1:49300` / `8787`，或用环境变量
`BP_DSH_URL` 指定。认证二选一：`BP_DSH_TOKEN`（插件配置的 apiToken，常驻推荐）或
`BP_DSH_CONNECT_TOKEN`（DSH 启动令牌，GUI 地址 `?token=` 里取）。启动方式：

```bash
BP_DSH_URL=http://127.0.0.1:8787 BP_DSH_TOKEN=<apiToken> npm run server
```

最小化示例见 `_projects/agent-smoke/`
（开始 → 创建 Agent 会话 → 发送 Agent 消息 → 打印「完毕」）。

| 虚幻5 | 本引擎 |

| USTRUCT / 结构体数组 | My Blueprint「类型」：定义字段 → `struct.make` / `struct.break` 动态引脚 → 列表列定义一键生成 |
| BeginPlay / 事件 | 开始 / 日志行 / 定时 |
| OnlineSubsystem | 后端：WS 源适配器与 RPC（adb/文件/RDS/飞书） |
| Content Browser / 资产 | 「资产」页签：后端静态目录 + 清单序列化显示 |
| 蓝图 ⇄ C++ | 蓝图 ⇄ 脚本 DSL（`{ } 脚本` 按钮，双向无损互转，含子蓝图段落；结构体节点暂不进入脚本视图，见 ADR-019） |
| PIE 调试可见性 | 运行时节点高亮 + **exec 连线流动动画** + **数据端口实时值** |
| 打包运行 | 后端可直接托管 dist/，同端口提供 WS |

## 内置节点（src/nodeRegistry.ts，声明式注册）

- **事件**：开始、日志行（流式）、定时、按钮点击、值变化
- **源**：演示日志（模拟会话/轮次/高频行）、手机日志（adb logcat）、日志文件（回放+监听追加）
- **处理**：正则匹配、格式化、转JSON、标签配色、转数字
- **界面**：读取界面值、设置界面值、列表·添加行、列表·清空
- **逻辑**：条件分支、延时（异步）、与
- **变量**：读取 / 写入
- **资产**：资产清单、资产地址
- **报表**：取报表数据（RDS RPC）、填报表模板（mustache 子集）、推送飞书
- **子蓝图**：调用节点（随子蓝图定义动态生成）+ 入口/出口系统节点
- **动作/数据**：打印、常量×3、相加

新增节点只需在注册表追加一条定义；新增子蓝图在图导航「＋ 子蓝图」，
接口（参数/返回）在子图编辑器的属性面板配置，主图中自动出现调用节点。

## 运行时架构

```
┌ 浏览器 ───────────────────────────────────┐   ┌ 后端 :8790 ──────────────────┐
│ 编辑器（蓝图 / 脚本 视图）                   │   │ WS Hub（插件运行/停止/RPC）    │
│ 运行时：Worker 解释器（串行事件队列）        │←─│ 源适配器: demo / adb / file    │
│  ├ trace/traceEdge → 节点高亮+连线流动      │WS│ 资产仓: 上传/清单/静态服务      │
│  ├ pinValue → 端口实时值（150ms 批量）      │   │ RPC: report.getStats (mock)   │
│  └ Agent 通知 / 插件推送 → 蓝图            │   │      feishu.pushDoc (webhook) │
└──────────────────────────────────────────┘   └───────────────────────────────┘
```

- 事件之间串行排队（日志顺序稳定）；RPC 回执与 UI 状态镜像**绕过队列**（避免与等待中的执行链死锁）
- 子蓝图执行：解释器作用域栈递归进入子图，入口/出口节点与调用帧交换参数与返回值
- 图数据净化：hydrate 与运行前都会丢弃引用不存在节点/端口的连线（**纯节点没有 exec 端口，
  exec 链不能穿过纯节点**——连线校验在编辑时拦截，净化兜底）

## 真实接入点（当前为存根/mock）

| 能力 | 现状 | 接入方式 |
|---|---|---|
| RDS 报表数据 | `server/rpc.ts` 返回模拟统计 | 换成调用 RDS 埋点平台 API |
| 飞书推送 | 未配置时生成本地 MD 文件入资产库 | 环境变量 `FEISHU_WEBHOOK` 即走真实 webhook |
| 手机日志 | 需要后端主机装 adb 并连设备 | `adb logcat`，包名经变量解析后过滤 |
| 插件存储 | 浏览器 IndexedDB | 需要多端同步时可迁移到后端 |
