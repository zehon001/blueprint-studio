# Blueprint Studio · 可视化插件引擎

类似虚幻引擎的**可视化插件制作与运行平台**：用蓝图定制各 SDK 中间件的观测、稳定性分析、行为分析与报表，一键运行并持续输出。

- 前端：React 18 + TypeScript + Vite + React Flow（编辑器 + 运行时）
- 后端：Node + WebSocket（源适配器 / 资产仓 / RPC），**无轮询，全实时推送**
- 引擎：Web Worker 图解释器（控制流 + 数据流混合，仿 UE 蓝图语义）

## 快速开始

```bash
npm install
npm run server    # 后端 :8790（WS + 资产 + RPC）
npm run dev       # 前端 :5173（另开一个终端）
npm run typecheck # 类型检查
npm run roundtrip # 蓝图⇄脚本往返一致性单测
npm run build     # 生产构建（后端可直接托管 dist/）
```

首次打开自动种子「Dolphin 轮唱SDK」中间件和两个示例插件：**日志查看器**、**错误报表**。

## 内置节点（src/nodeRegistry.ts，声明式注册）

- **事件**：开始（BeginPlay）、日志行（流式）、定时
- **源**：演示日志（模拟 Dolphin 会话/轮次/高频日志）、手机日志（adb logcat）、日志文件（回放 + 持续监听追加）
- **处理**：正则匹配、格式化、标签配色、转数字
- **逻辑**：条件分支、延时（异步潜藏节点）、与
- **变量**：读取 / 写入（运行时可变）
- **资产**：资产清单、资产地址
- **报表**：取报表数据（RDS RPC）、填报表模板（mustache 子集）、推送飞书
- **输出**：日志树（会话/轮次/条目）、Markdown、流程图（节点/连线/激活）
- **动作**：打印
- **数据**：文本/数字/布尔常量、相加

新增节点只需在注册表追加一条定义——节点库、端口渲染、连线校验、脚本互转、执行引擎全部自动生效。

## 运行时架构

```
┌ 浏览器 ────────────────────────────────┐   ┌ 后端 :8790 ──────────────────┐
│ 编辑器 (React Flow + zustand)           │   │ WS Hub（插件运行/停止/RPC）    │
│ 运行时: Worker 解释器（串行事件队列）      │←─│ 源适配器: demo / adb / file    │
│   ├ trace → 节点执行高亮                 │WS│ 资产仓: 上传/清单/静态服务      │
│   ├ fx(widget) → 小组件状态机 → React    │   │ RPC: report.getStats (mock)   │
│   └ rpc ⇄ 主线程 ⇄ 后端                  │   │      feishu.pushDoc (webhook) │
└────────────────────────────────────────┘   └───────────────────────────────┘
```

- 事件之间串行排队（日志顺序稳定）；**RPC 回执绕过队列**（否则与等待中的执行链互相死锁）
- 小组件状态机（`src/widgets/reducers.ts`）与渲染组件分离，新增小组件 = 注册 reducer + 组件
- 蓝图脚本 DSL：`plugin / var / node 别名(参数) / edge a.port -> b.port`，
  往返一致性由 `npm run roundtrip` 保证

## 真实接入点（当前为存根/mock）

| 能力 | 现状 | 接入方式 |
|---|---|---|
| RDS 报表数据 | `server/rpc.ts` 返回模拟统计 | 换成调用 RDS 埋点平台 API |
| 飞书推送 | 未配置时生成本地 MD 文件入资产库 | 环境变量 `FEISHU_WEBHOOK` 即走真实 webhook |
| 手机日志 | 需要后端主机装 adb 并连设备 | `adb logcat`，包名经变量解析后过滤 |
| 插件存储 | 浏览器 IndexedDB | 需要多端同步时可迁移到后端 |
