# ADR-001：统一 IR（逻辑资产中间表示）

| 状态 | 日期 | 关联卡 | 影响范围 |
|---|---|---|---|
| 已接受 | 2026-10-17 | T0.1 | `src/ir/`、`src/blueprint/`、`src/script/`、`src/runtime/`、`src/nodes/` |

## 1. 决策内容

- 所有逻辑资产（蓝图 / TS 脚本 / Python 脚本）在内存中统一表示为 **IRAsset**（PLAN §5，落实 D3「单一资产双视图」）：
  - 蓝图视图 = IR 的图渲染；脚本视图 = codegen(IR)；脚本文本 = parse(受控子集) → IR。
  - `.bp.json` 直接序列化 IR 存储；`.ts` / `.py` 存源码，加载时解析为同构 IR。
- 边语义沿 UE5：**exec 边 + 数据边**，且 **exec 链不能穿过纯节点**（`NodeSpec.pure = true` 的节点没有 exec 引脚，编辑时拦截，见 ADR-003）。
- IR 携带 `version`；格式变更必须先落 ADR，并经 `migrateIR` 迁移（当前为初始版本 2，直通实现）。
- **唯一真源**：类型定义在 `src/ir/types.ts`，其他模块一律 import，不得重复声明；校验器（T2.8 `src/ir/validate.ts`）与解释器（T2.5）共用其中的类型守卫。

## 2. 结构定义

类型真源：[src/ir/types.ts](../../../src/ir/types.ts)（字段级说明以 JSDoc 为准，此处仅列要点）。

| 类型 | 用途 | 关键约束 |
|---|---|---|
| `IRAsset` | 逻辑资产根对象 | `version = 2`；`entry` 指向 `graphs` 的键（主图名） |
| `IRGraph` | 一张图（主图 / 函数子图） | 函数子图可带 `params` / `returns`（函数入口 / 出口节点据此渲染引脚） |
| `IRNode` | 节点实例 | `type` 指向 `NodeSpec.id`；`pinDefaults` 存未连线输入引脚的内联默认值 |
| `IREdge` | 连线 | `kind = 'exec' \| 'data'`，端点为 `{ node, pin }` |
| `IRVariable` | 变量 | `exposed = true` → 自动生成 Get/Set 节点 + 脚本 `@expose` |
| `IREventDef` | 自定义事件 | 发送事件 / 监听事件节点的目标 |
| `IRSnippet` | 脚本片段节点 | 互转不可映射段的兜底，保证往返无损（T3.7 细化挂接） |
| `IRGraphLayout` | 图的视图状态 | 仅蓝图视图使用，不参与解释，roundtrip 测试可忽略 |

值类型系统（`IRValueType`）：

- 内置原语：`exec | bool | int | float | string | object | any`。PLAN §5 示例中的 `number` 在本契约定型为 `float`（整数用 `int`）。
- 数组：任意元素类型加 `[]` 后缀（如 `string[]`、`LogRow[]`）。
- 自定义对象类型：字符串别名（如 `LogRow`、`file`），由节点库 / 插件声明并按名引用，解释器不做结构展开。
- 可赋值性（校验器基础规则，实现见 `isTypeAssignable`）：同型 / 任一侧 any / `int → float` / 数组同形；其余需显式转换节点（T2.2 自动插入）。
- 类型守卫工具：`isExecType` / `isPrimitiveType` / `isArrayType` / `elementType` / `isNumericType` / `isAnyType` / `isTypeAssignable`，供校验器与解释器使用。

## 3. 示例（完整 IR）

扩展自 PLAN §5 示例，字段与 `src/ir/types.ts` 逐一对应（节点 `type` 的具体 id 以 `src/nodes/` 实现为准，此处为示意）：

```jsonc
// MyTool/logic/main.bp.json
{
  "version": 2,
  "name": "日志查看器",
  "entry": "bind",
  "graphs": {
    "bind": {                                  // 主图（绑定 UI 节点时的事件入口图）
      "nodes": [
        {
          "id": "n1", "type": "event.start",
          "params": {}, "pinDefaults": {},
          "position": { "x": 80, "y": 240 },
          "comment": "BeginPlay 同义"
        },
        {
          "id": "n2", "type": "phoneLog.read", "title": "读取手机日志",
          "params": { "source": "file" },                      // 节点参数（检视器编辑）
          "pinDefaults": { "packageFilter": "com.demo.app" },  // 未连线引脚的内联默认值
          "position": { "x": 380, "y": 240 }
        },
        {
          "id": "n3", "type": "ui.call", "title": "写列表",
          "params": { "node": "list", "method": "setItems" },
          "pinDefaults": {},
          "position": { "x": 700, "y": 240 }
        }
      ],
      "edges": [
        { "id": "e1", "from": { "node": "n1", "pin": "exec" }, "to": { "node": "n2", "pin": "exec" }, "kind": "exec" },
        { "id": "e2", "from": { "node": "n2", "pin": "exec" }, "to": { "node": "n3", "pin": "exec" }, "kind": "exec" },
        { "id": "e3", "from": { "node": "n2", "pin": "rows" }, "to": { "node": "n3", "pin": "arg0" }, "kind": "data" }
      ]
    },
    "parseLog": {                              // 函数子图（主图经函数调用节点调用）
      "nodes": [
        { "id": "f1", "type": "func.entry",    "params": {}, "pinDefaults": {}, "position": { "x": 80,  "y": 120 } },
        { "id": "f2", "type": "convert.androidLog", "params": {}, "pinDefaults": {}, "position": { "x": 360, "y": 120 } },  // 纯节点
        { "id": "f3", "type": "container.sortBy",   "params": { "key": "ts" }, "pinDefaults": {}, "position": { "x": 640, "y": 120 } }, // 纯节点
        { "id": "f4", "type": "func.return",   "params": {}, "pinDefaults": {}, "position": { "x": 900, "y": 120 } }
      ],
      "edges": [
        // exec 链不能穿过纯节点：f2/f3 无 exec 引脚，其结果经数据边被 func.return 的输入拉动
        { "id": "e4", "from": { "node": "f1", "pin": "exec" },  "to": { "node": "f4", "pin": "exec" },  "kind": "exec" },
        { "id": "e5", "from": { "node": "f1", "pin": "lines" }, "to": { "node": "f2", "pin": "raw" },   "kind": "data" },
        { "id": "e6", "from": { "node": "f2", "pin": "rows" },  "to": { "node": "f3", "pin": "items" }, "kind": "data" },
        { "id": "e7", "from": { "node": "f3", "pin": "sorted" }, "to": { "node": "f4", "pin": "rows" }, "kind": "data" }
      ],
      "params":  [ { "name": "lines", "type": "string[]" } ],   // 函数接口：入口节点渲染
      "returns": [ { "name": "rows",  "type": "LogRow[]" } ]    // LogRow = 自定义对象类型别名
    }
  },
  "variables": [
    { "name": "packageName", "type": "string",  "default": "com.demo.app", "exposed": true, "category": "配置" },
    { "name": "rows",        "type": "LogRow[]",                       "category": "数据" }
  ],
  "events": [
    { "name": "loaded", "params": [ { "name": "count", "type": "int" } ] }   // emit('loaded', { count }) 的目标
  ],
  "snippets": [
    {                                   // 脚本片段节点（互转兜底，不可映射段原样保留源码）
      "id": "snip1", "lang": "ts",
      "code": "return rows.filter(r => r.level === 'E').length;",
      "pins": [
        { "id": "rows",     "dir": "in",  "type": "LogRow[]" },
        { "id": "errCount", "dir": "out", "type": "int" }
      ]
    }
  ],
  "layout": {                           // 视图状态：仅蓝图视图使用
    "bind":     { "zoom": 1,   "pan": [0, 0] },
    "parseLog": { "zoom": 0.8, "pan": [-120, 40] }
  }
}
```

## 4. 变更流程

1. Arch-Agent 在 `docs/v2/adr/` 新增 ADR（编号递增），写明变更点、受影响字段与迁移方案，知会 PM-Agent。
2. PM-Agent 广播到受影响的在途卡。
3. 修改 `src/ir/types.ts`：若格式版本变化，`IRAsset.version` 的字面量类型扩展为新联合（如 `2 | 3`），并在 `migrateIR` 中按版本接迁移链（迁移后必须等于 `IR_VERSION`）。
4. roundtrip 测试（TA.1）补样例；校验器（T2.8）按需补规则。
5. 禁止绕过 ADR 直接修改本契约。

**遗留 / 预留（后续 ADR 扩展）**：

- `IRParamSpec` 当前仅 `name + type`（事件参数与函数接口够用）；如需参数描述 / 默认值，走 ADR 扩展。
- `IRSnippetPin` 为最小骨架（id / dir / type / label）；片段节点在图中的挂接方式（IRNode 如何引用 snippet id）由 T3.7 定。
- `migrateIR` 当前直通；首次 IR 格式变更时引入版本判定与迁移链。
