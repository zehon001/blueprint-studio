# Blueprint Studio v3 · 用户手册

> 面向工具使用者（UE5 / Godot 背景）。基准版本：2026-10-18（v3 长分支，M8~M13 增量；v2 行为仍兼容）。
> v3 新增能力速查见文末「附录 B · v3 增量」。
> 本手册所有节点名、引脚名、API 与行为均逐项对照源码核对（`src/nodes/`、`src/runtime/`、`src/script/`）。
> 与设计稿（`docs/v2/PLAN.md` §9.2 示例等）不一致处以实现为准，差异集中列在 §11。

---

## 0. 这是什么

Blueprint Studio 是一个**工具制作引擎**（网页版）：外观与操作复刻 Godot 编辑器，蓝图复刻 UE5，用来制作「UI 工具类软件」——手机日志分析器、报表推送器等，而不是游戏。

- **做工具**：只有 UI 相关能力（控件、布局、事件），没有物理 / 角色 / 动画。
- **蓝图 ⇄ 脚本**：同一份逻辑资产两个视图（`.bp.json` 蓝图 / `.ts` 脚本），互转无损。
- **内置运行视图**：F5 / F6 在编辑器「运行」tab 内以 iframe 运行（可拆出独立窗口），编辑器里能实时看到节点高亮、连线流动、端口实时值；保存成功可自动重跑。
- **插件**：外部 CLI（adb、feishu 等）的检测 / 安装 / 更新 + 节点封装。

词汇对齐（全局统一，不叫「场景 / 信号」）：

| UE5 / Godot | 本引擎定名 |
|---|---|
| Project | 工具项目（文件夹 + `project.json`） |
| Scene / Widget Blueprint | **UI**（`*.ui.json`） |
| Signal / Delegate | **事件** |
| Inspector / Details | 检视器 |
| Run (F5) / PIE | 运行（独立浏览器窗口） |

## 1. 快速上手

### 1.1 启动

```bash
npm install
npm run server   # 本地服务 :8790（文件 / 转译 / 插件 / WS）
npm run dev      # 编辑器 :5173（另开终端；/api、/ws 已代理到 8790）
```

浏览器打开 `http://localhost:5173` 进入**项目管理器**（构建后也可由本地服务直接托管 `dist/`）。

### 1.2 项目管理器

- **最近**：最近打开的项目列表。
- **新建**：输入名称 + 选模板（`空项目` / `日志分析器`），创建后直接进入主编辑器。
- **导入**：选择磁盘上任意文件夹导入为项目。

项目即文件夹（Godot 习惯）：`project.json`（主 UI、引擎版本、启用插件）+ `ui/`（UI 资产）+ `logic/`（逻辑资产）+ `assets/`（静态资源）。

### 1.3 五分钟跑通「日志分析器」模板

模板开箱可跑，蓝图为 `读取文件 → 解析Android日志 → 设置列表项 → 打印` 链：

1. 项目管理器 → 新建 → 模板选**日志分析器** → 进入编辑器。
2. 直接按 **F5**（运行主 UI）→ 弹出独立运行窗口，列表显示示例日志（`assets/sample.log`，10 行）。
3. 运行窗口顶部「控制台」条可展开，看到 `[绑定] 已加载 logic/main.bp.json…` 与打印输出。
4. 回编辑器，文件系统面板双击 `logic/main.bp.json` 打开**蓝图编辑器**查看这条链。
5. 修改蓝图（如给 `解析Android日志` 的检视器参数「级别过滤」选 `E`）→ Ctrl+S 保存 → F5 重跑验证。

## 2. 主编辑器布局

```
┌ 顶栏：项目名 · 运行▶(F5) 运行当前(F6) · 调试 · 保存(Ctrl+S) · 撤销/重做 · 面板▾ · 重置布局 ┐
├ 左列                ├ 中央工作区（tabs）            ├ 右列                ├
│ 文件系统面板        │ UI 编辑 / 蓝图编辑 / 脚本 /   │ 检视器              ├
│ UI 树面板           │ 插件管理                      │ 事件面板            ├
├────────────────────┴───────────────────────────────┴ 底部：控制台 ────────┤
```

- **所有面板可拆出 / 合回**：拖面板标题栏到边缘吸附成 tab；点标题栏「拆出窗口 ⊞」弹为独立浏览器窗口（多窗口状态实时同步；被浏览器拦截时降级为新标签页）。顶栏「面板 ▾」可开 / 关任意面板，「重置布局」恢复默认。
- **工作区 tab**：文件系统面板双击资产打开；tab 脏标记 ● 表示未保存；Ctrl+S 保存。
- 撤销 / 重做：Ctrl+Z / Ctrl+Shift+Z（或 Ctrl+Y），覆盖蓝图、UI 树、检视器、文件操作（文件删除经 `.history` 快照可撤销）。

## 3. UI 编辑器

### 3.1 UI 节点库（4 类 23 种）

选中 UI 树面板空白 / 容器节点右键「添加节点」，或视口内操作。每节点有 `name`（树内唯一，`ui.<name>` 查找键）、Transform（位置 / 尺寸 / 旋转）、主题样式、业务属性。

| 分类 | 节点 | 内建事件 |
|---|---|---|
| 容器 | vbox、hbox、grid、scrollBox、tabContainer、splitContainer、panel | panel=`mouseEnter` / `mouseLeave`，其余无 |
| 显示 | label、richText、markdown、image、separator、progressBar | — |
| 输入 | button、checkBox、lineEdit、textEdit、optionButton、slider、spinBox | button=`pressed`；checkBox=`toggled`；lineEdit=`textChanged` + `submit`（回车）；textEdit=`textChanged`；optionButton=`selectedChanged`；slider / spinBox=`valueChanged` |
| 数据 | list、table、tree | =`selectionChanged`、`doubleClicked` |

> List 的「列定义」（columns）支持字段 / 标题 / 宽度 / 颜色映射（colorRules）/ 分组（groupBy）/ 合并计数（mergeDuplicates），日志条目显示完全自由。

### 3.2 视口（2D）

选择 / Shift 框选加选 / 拖拽移动 / 方向键微调 / 对齐吸附线 / 滚轮缩放；所有操作入命令栈可撤销。

### 3.3 UI 树面板

- 拖拽重排父子关系；双击行内重命名（重名拒绝）。
- 右键菜单：添加子节点（仅容器，带分组搜索浮层）/ 复制 / 重命名 / 附加逻辑资产（建议用检视器）/ 保存为预制体（子树导出 `ui/prefabs/` 并就地转实例，T7.3）/ 删除（confirm，根节点不可删）。

### 3.4 检视器

- Schema 驱动：分组折叠、属性搜索过滤、多选显示共同属性（混合态）、修改即入命令栈。
- **「逻辑资产」属性（每个 UI 节点都有）**：下拉选择 `logic/` 下的 `.bp.json` / `.ts`（也可「新建」）。挂载后运行窗口由该逻辑资产驱动此节点**及其子树**——蓝图的 `ui` 访问器、`ui.get` / `ui.setValue` 等节点按 name 查找的范围即这棵子树。
- 选中节点时同时列出其内建事件（与事件面板联动）。

### 3.5 事件面板

选中 UI 节点后面板分两节：

1. **内建事件**：该节点类型的全部事件（如 button 的 `pressed`）。
2. **自定义事件**：所挂逻辑资产里声明的事件（含参数签名）。

- **双击内建事件** → 已有入口则跳转选中，缺失则自动在蓝图创建事件入口节点（未挂逻辑资产时先引导新建蓝图并挂载）。
- **双击自定义事件** → 跳转；缺失时给「一键创建」按钮。
- 右键行：跳转 / 创建、复制事件名。

---

### 3.6 预制体（T7.3 · ADR-009）

- **保存为预制体**：选中节点子树 → UI 树右键「保存为预制体」→ 命名后写入 `ui/prefabs/<名>.ui.json`，原节点**就地转为实例**（树内带 ⧉ 徽标）。可撤销。
- **插入预制体实例**：画布空白 / 容器上右键 →「添加节点 → 预制体（ui/prefabs/）」分组 → 点选即插入实例（名字自动去重；尺寸/类型取预制体设计值）。
- **编辑预制体**：双击实例（或右键「编辑预制体」）打开预制体本体；保存后改动**反射到全部引用处**（打开资产 / 运行刷新时生效）。
- **实例覆盖**：实例可覆盖主题样式 / 业务属性 / 事件与逻辑绑定（检视器直接改）；结构（类型 / 子树）以预制体为准——实例拒收子节点。
- **断开预制体**：检视器「断开」把实例物化为普通子树（当前有效值冻结，可撤销）。
- **循环引用**：预制体嵌套自身会被检测并阻断（运行窗口装载期报错，编辑器就地占位不阻断）。

## 4. 蓝图编辑器

### 4.1 界面组成

- **My Blueprint（结构面板，左侧）**：变量 / 函数 / 事件 / 注释 四分节；双击条目跳转对应图（图以 tabs 切换）。
- **画布（中央）**：暗色网格、无限平移缩放（0.2×~2.5×）、UE5 式节点（分类配色头：事件=红、函数=蓝、纯函数=绿、流程=灰、变量=无头紧凑、插件=紫）、exec 白实线 / 数据彩虚线。
- **检视器（右侧）**：选中节点显示参数（下拉 / 输入）、引脚默认值、节点说明（`doc`）；无选中显示当前图的「图接口」（函数入参 / 返回值）。
- **校验条（底部）**：Ctrl+S 保存前自动校验，错误列表点击跳节点。

### 4.2 画布交互（UE5 招牌操作）

| 操作 | 方式 |
|---|---|
| 添加节点 | 画布右键 → 搜索菜单（模糊匹配 + 分类浏览 + 最近使用）；**Tab** 在光标处呼出 |
| 从引脚拖出连线 | 松开在空白 → 只列兼容节点的菜单，选中即建并自动连线；拖到类型不符引脚 → 自动插入转换节点 |
| 断开连线 | 右键连线；**Alt+点击引脚**断开该脚全部连线 |
| 选择 | 点选 / 框选；Shift+框选为加选 |
| 复制 | Ctrl+C/X/V（跨图可用）；**Ctrl+拖拽节点 = 复制到落点**（原位保留） |
| 删除 | Delete；全选 Ctrl+A |
| 平移 / 缩放 | 鼠标中键平移，滚轮以光标为中心缩放 |
| 注释框 | 右键「添加注释」；拖标题带动框内全部节点；可调色（UE5 Comment 行为） |

### 4.3 My Blueprint

- **变量**：类型 / 默认值 / 分类；勾选**「暴露」**后自动生成 Get / Set 节点（右键搜索或插入），脚本视图对应 `@expose` 字段。运行时暴露变量写入会同步到绑定 UI。
- **函数**：「＋函数」建子图；函数图含入口 / 出口接口节点；主图出现「调用函数」节点（检视器填目标函数，或 My Blueprint 函数条目右键「插入调用」）。
- **事件**：自定义事件列表（双击跳转入口节点）。

### 4.4 函数（子图）

- 函数图 = `func.entry`（入口，输出 = 入参）+ `func.return`（出口，输入 = 返回值）；入参 / 返回值在检视器「图接口」区（无选中时）编辑。
- 主图用「调用函数」节点调用，压独立栈帧执行，入参 / 返回值随接口声明变化。
- 图内变量作用域：函数内先读帧入参，再读资产变量。

### 4.5 保存与校验

Ctrl+S → 序列化 IR 到 `.bp.json`（保存即校验，无显式「编译」步骤）。校验器会报：未知节点、悬空 exec、exec 链穿过纯节点、类型不匹配 / 需窄化转换、重复节点 id、断线、事件无入口、未使用变量等，点击条目跳转节点。

### 4.6 ★ 循环 / 序列 / 定时器：一次触发全程执行（无需回连）

> 这是 v2 的关键语义（ADR-008），**与旧版「链尾回连」状态机相反，与 UE5 一致**：循环体 / tick / 序列子链的尾端**不需要**连回节点自己的 exec 入。

| 节点 | 新语义（当前实现） |
|---|---|
| **For 循环** `flow.forLoop` | 一次触发跑完 from→to（含，step 支持负数）：每迭代执行「循环体」子链**完整跑完**后才进入下一迭代；结束（含 break）走「完成」。**循环体不要回连**——旧资产里回连的边会被自动忽略（安全降级为 no-op）。 |
| **While 循环** `flow.whileLoop` | 一次触发内循环：每迭代**重估条件**（条件接 `获取变量` 可动态退出），真执行循环体，假或 break 走「完成」。 |
| **序列** `flow.sequence` | 一次触发按序激活 out0→out3，每条子链完整执行后才下一条。 |
| **定时器** `event.timer` | 一次触发自动持续计时：每 interval 秒触发一次「每次触发」出脚（loop=true）；loop=false 时到期先触发一次「每次触发」，再走「结束」。`取消` 引脚或运行中止走「结束」。interval / loop / cancel **每 tick 重估**——接变量可实现动态调速 / 停止。tick 边界为**协作让出点**（ADR-010）：无条件循环运行中，其它事件（按钮点击等）最迟在下次 tick 前被派发（延迟上限 ≈ interval），不再被饿死。 |
| **遍历数组** `array.forEach` | 一次触发遍历完（触发时快照数组），每元素执行「循环体」后继续；break 每迭代重估；遍历完走「完成」。 |

提前终止模式：循环体的 `break` 引脚接 `获取变量`，循环体内用 `设置变量` 写该变量为 true——下一迭代条件重估后退出（for / while / forEach 均支持）。

> 有状态触发的节点（`门` / `A/B 切换` / `仅一次` / `多路复用`）保持 UE5 语义不变：门用 `open` 数据引脚控制（接变量实现开 / 关 / 切换）。

### 4.7 事件与事件路由

- **入口节点**：`开始`（运行加载后触发一次，BeginPlay 同义）、`自定义事件`（检视器填事件名，或事件面板双击创建）、`监听事件`（eventName 引脚指明目标事件）。
- **发送事件**：args 传对象按键展开为事件参数；`路由目标` 引脚选择 `本节点` / `本 UI 实例` / `全部实例`——经事件总线投递到其它蓝图 / 其它 UI 实例（环保护，`开始` 事件不广播）。
- 事件串行排队保序（循环定时器等多次出脚节点的 yield 边界为协作让出点，积压事件在此派发，ADR-010）；事件参数按名注入入口节点同名输出脚（自定义事件还提供 arg0~arg2 占位脚；UI 事件额外注入**来源节点**脚 = 触发节点名，同一蓝图绑多控件时可接分支按来源分派）。
- 定时器每次到期会向总线发布系统事件 `timer`（参数 `ticks`），其它蓝图可 `监听事件` 接收。

## 5. 脚本系统（受控 TS）

### 5.1 双视图

`.ts` 逻辑资产的 tab 顶部有 **[蓝图 | 脚本] 切换条**：同一 IR 的两个视图。

- 脚本视图：CodeMirror 编辑，顶部诊断徽标（点击跳行列）；解析 error 时蓝图视图降级只读。
- **保存者胜**：两侧同开时后保存者生效，另一侧切回提示重载；蓝图视图保存 = 改 IR → codegen 生成 TS **覆盖写盘** `.ts` 源码。
- `.py` 资产本期只提示不执行（Python 运行时 T4.x 未接入）。

### 5.2 受控子集写法规则

脚本不是任意 TS，能映射为蓝图节点的子集才不折叠（超集语句折叠为**脚本片段节点**，仍可运行但蓝图视图不可见）：

```text
@tool('资产名')  class Xxx {          ← 逻辑类（唯一类）
  @expose({...}) 字段                  ← 变量（蓝图可见，可勾暴露）
  @on('start') / @on(事件名) 方法      ← 事件入口（开始 / 自定义事件）
  @on('节点名', '事件名') 方法          ← 监听 UI 内建事件（双参取第二参）
  @onEvent(事件名) 方法                 ← 监听自定义事件（方法参数 = 事件参数对象 args）
  普通方法                              ← 函数图；this.fn() → 调用函数节点
}
```

语句映射：`if/else` → 分支；`for / for..of / while` → 循环（循环变量以先前声明的 `let` 承载——`let i;` 后接 `for (i = 0; …)`，这是 codegen 的往返写法）；`await delay(X)` → 延时；`emit(...)` → 发送事件；`await readFile(p)` → 读取文件；`print(v)` → 打印；`ui.<节点>.<属性> = v` → 写值；`this.x = v` / `vars.x = v` → 设置变量；`this.x` / `vars.x` 读 → 获取变量；表达式 → 纯节点链。

**必须知道的限制**（折叠为片段不算错，但蓝图视图不可见）：

1. **不支持局部变量**：方法体内的 `const` / `let` 会折叠。中间值用 ① 引擎别名行 `const __bps_v1 = <表达式>`（codegen 的中间值写法，解析端会还原成节点），或 ② 存进 `vars.*` 后续引用。
2. **print 语句只接受 1 个参数**：多值拼接用 `format('共 {0} 行', n)`。
3. **await 只能作为独立语句**（或 `delay` / `readFile` 的别名行形态），不能出现在普通表达式里。
4. **delay 单位是毫秒**（蓝图「延时」节点输入是**秒**，脚本视图自动 ×1000 换算）。
5. 等于 spec 默认值的显式引脚值一次往返后会归一为缺省（语义不变）。

### 5.3 内建全局（9+1）

| 全局 | 说明 |
|---|---|
| `ui` | UI 访问器。属性式：`ui.<节点名>.text/.value/.checked/.visible/.items/...` 直接读写（作用域 = 绑定节点子树）；通用方法 `ui.find(name)` / `ui.read(name, attr)` / `ui.write(name, attr, value)`。节点不存在 → 返回安全空对象并警告一次，不抛错。 |
| `vars` | 资产变量代理：`vars.x` 读 / `vars.x = v` 写；`Object.keys(vars)` 列出全部。 |
| `emit(name, ...args)` | 发送自定义事件。参数规范化与「发送事件」节点一致：对象按键展开 / 数组打包为 `args` / 单值打包为 `value`；多参数位置式 `arg0..n`。**要与事件参数名对上，请传对象**：`emit('loaded', { count: n })`。 |
| `onEvent(name, handler)` | 监听事件（handler 参数 = 事件参数对象）。等价 `@onEvent` 方法。 |
| `plugins` | 插件调用命名空间：`await plugins.<插件id>.<方法>(...args)`。当前约定见 §5.6 差异注记（方法名须传完整节点 id，见下）。 |
| `print(...)` | 打印到运行窗口控制台（旁路直调，不入事件队列）。 |
| `readFile(path)` | 读项目内文件文本（路径相对项目根）；失败降级返回空串并提示。 |
| `convert` | 与转换节点同语义：`toNumber / toString / toBool / parseInt / jsonParse / jsonStringify / timeFormat(epochMs, fmt?) / androidLogParse(lines, levelFilter?)`。失败一律安全降级（0 / 空串 / false / null），不抛错。 |
| `format(tpl, ...args)` | `{0} {1}…` 占位符替换，缺参为空串（string.format 节点同语义）。 |
| `delay(ms)` | 异步延时（毫秒）；不阻塞其他事件；运行停止时以 AbortError 中止。 |

### 5.4 示例：把「日志分析器」模板写成脚本（可复制运行）

在模板项目 `logic/` 下新建 `parser.ts`（文件系统面板右键新建文件），双击打开，粘贴以下内容并 Ctrl+S：

```ts
@tool('日志查看器')
class LogViewer {
  // 暴露变量：蓝图 My Blueprint 出现同名变量（勾选「暴露」）
  @expose({ type: 'string', default: 'com.demo.app' })
  packageName: string = 'com.demo.app'

  // 「开始」事件（BeginPlay 同义）：运行窗口加载 UI 后触发
  @on('start')
  async onStart(): Promise<void> {
    ui.title.text = '日志分析'
    // __bps_v 别名行 = 引擎中间值写法（解析端还原为节点，勿改名）
    const __bps_v1 = await readFile('assets/sample.log')
    const __bps_v2 = convert.androidLogParse(__bps_v1)      // → LogRow[]（ts/level/tag/pid/msg/raw）
    ui.list.items = __bps_v2                                 // 写 List 行数据
    print(format('已加载 {0} 行日志', __bps_v2.length))
    emit('loaded', { count: __bps_v2.length })               // 对象参数按事件参数名展开
    await delay(500)                                         // 非阻塞延时 0.5 秒
  }

  // 监听自定义事件（等价蓝图「监听事件」节点；方法参数 = 事件参数对象）
  @onEvent('loaded')
  onLoaded(args: unknown): void {
    print(args)
  }
}
```

F5 运行：与模板蓝图等价——列表显示解析后的日志行，控制台输出 `已加载 10 行日志` 与事件参数。切到 [蓝图] 视图可看到这条链对应的节点（该示例零折叠，全部映射为蓝图节点）。

> 监听 UI 内建事件的写法：`@on('list', 'selectionChanged')`（双参 = 节点名 + 内建事件名；list 的事件名是 `selectionChanged`）。

### 5.5 脚本片段节点

不可映射语句折叠成的 `脚本片段` 节点保留源码与声明引脚（往返无损）；蓝图视图双击片段节点可展开模态编辑源码。运行时片段以函数形式执行，可访问全部内建全局。

### 5.6 与 PLAN §9.2 示例的差异（以实现为准）

设计稿 §9.2 的示例是示意，以下差异经源码核对后在本文档按实现收录：

1. **`convert.androidLog(lines).sort(byTime)` 不存在** → 实现为 `convert.androidLogParse(lines, levelFilter?)`；排序用蓝图的「数组排序」节点（按字段 + 升 / 降序，无比较器回调形态）。
2. **`plugins.phoneLog.read({ mode: 'adb', filter: ... })` 不成立** → 见 §8.4：脚本内调用插件的可用形态是 `await plugins['phone-log']['phoneLog.read']({...})`（插件 id 原文 + 完整节点 id），参数名是 `mode('device'|'file') / packageFilter / files`。且当前实现里**脚本片段运行环境未接入插件桥**——脚本里调插件请改用蓝图插件节点（见 §8.4 注记）。
3. **`emit('loaded', rows.length)` 传单值**会被打包为 `{ value: n }`，与事件参数名 `count` 对不上 → 请传对象 `{ count: n }`。
4. **`class LogViewer extends UILogic`**：`UILogic` 基类无声明（编辑器会有 TS 诊断）；解析器不要求继承，示例省略了 `extends`。
5. `@expose` 的 `type` 参数仅在字段无 TS 类型注解时兜底（优先级：行内 `@bps` 注释 > TS 注解 > `@expose type` > any）。

### 8.4 脚本里调插件（现状注记）

- 可靠方式：**蓝图插件节点**（或在脚本受控写法里映射为插件节点）。
- `plugins.*` 全局是两级动态代理，当前实现里脚本片段运行环境**未注入插件桥**，片段内调用会抛「插件桥未接入」；且能命中服务端执行器的调用形态为 `plugins['<插件id>']['<完整节点id>'](args)`（如 `plugins['phone-log']['phoneLog.read']({ mode: 'file', files: [...] })`）。该通道目前仅插件节点使用，脚本侧建议等后续版本统一。
